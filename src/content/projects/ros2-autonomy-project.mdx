## overview

This project was my final project for Intro to Robotics. The aim was to build a robot that can navigate to goal positions in several different environments. We were provided a template that had Gazebo and ROS bridged together as well as code for loading the different environments and the rest was up to us. While we were allowed to use the ground truth posisting from Gazebo, I decided to add some complexity and use the odometry estimate from the diffdrive plugin and add a SLAM node to correct for odometry drift.

## slam

In order to navigate through the unknown environments, I implemented a GraphSLAM node. The front end built a pose graph using filtered odometry messages and Iterative Closest Point scan matching to generate pose estimates and relative transforms. The back end used a Gauss-Newton optimizer to correct the pose graph when a loop closure was detected. The entirety of the GraphSLAM node was hand coded, including the optimizer and the ICP algorithm.

The SLAM node was also responsible for generating an occupancy map which was contructed by projecting laser scans onto a grid and using log odds probability to create an occupancy grid.

## path planning

The path planner consumed the occupancy grid generated by the SLAM node and would generate a path using an A* grid algorithm. However, before performing A*, the occupancy map was inflated first using a hard inflation boundary and then a distance map was generated using a hand rolled Euclidian Distance Transform algorith. this distance map is what was used for A* so that a cost function could be added to keep the robot from going too close to walls.

## path following

For path following a Regulated Pure Pursuit controller was implemented. Regulated Pure Pursuit was chosed over regular Pure Pursuit because some of the environments have narrow corridors and sharp corners so I wanted to have the robot slow down when navigating those situations to be more reliable.
