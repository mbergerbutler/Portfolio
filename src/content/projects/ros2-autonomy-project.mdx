## Overview

This was my final project for Intro to Robotics. The goal was to build a robot capable of navigating to goal positions across several unknown environments. We were given a starting template with Gazebo and ROS2 bridged together, along with code for loading the environments — the rest was left to us.

While ground truth pose data from Gazebo was available, I chose to work with the odometry estimate from the differential drive plugin and layer in a SLAM node to correct for drift, adding some meaningful complexity to the problem.

## SLAM

To navigate through unknown environments, I implemented a GraphSLAM node from scratch. The front end builds a pose graph using filtered odometry and ICP scan matching to generate pose estimates and relative transforms between nodes. The back end runs a Gauss-Newton optimizer to correct the graph when a loop closure is detected. The ICP algorithm and optimizer were both hand-coded.

The SLAM node also builds an occupancy map by projecting laser scans onto a grid and updating cell probabilities using log-odds.

## Path Planning

The path planner consumes the occupancy grid and generates a path using A*. Before running A*, the map is inflated with a hard boundary around obstacles, then a Euclidean Distance Transform (also hand-coded) produces a distance map. A* runs on this distance map with a cost function that penalizes proximity to walls, keeping the planned path away from obstacles.

## Path Following

Path following is handled by a Regulated Pure Pursuit controller. I chose Regulated Pure Pursuit over standard Pure Pursuit because several environments have narrow corridors and sharp corners — the speed regulation makes the robot more reliable in those situations.
